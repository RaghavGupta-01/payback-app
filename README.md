# PayBack

PayBack is a credit-card bill payment dashboard that rewards you with coins on every payment and gives you a clear view of your spending - built with Next.js, FastAPI, and PostgreSQL.

## Tech Stack

- Frontend: Next.js + TypeScript
- Backend: FastAPI + Python
- Database: PostgreSQL
- ORM: SQLAlchemy
- Database Hosting: Neon
